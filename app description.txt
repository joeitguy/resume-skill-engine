resume-skill-engine — Project Description

The resume-skill-engine is the core system that powers a fully automated resume‑to‑job‑description matching workflow. It’s built as a structured pipeline that ingests user data, processes it through an AI‑driven skill extraction and matching engine, and outputs customized application documents. The backend establishes all the foundational data models for work history, education, and a dynamic skills library, while exposing clean FastAPI endpoints for CRUD operations. On top of that foundation sits the LLM processing layer, which handles resume ingestion, job description analysis, semantic skill matching, and text generation for both cover letters and resume summaries.

The frontend is designed as a focused workspace with a static sidebar and a central “Skills Sandbox” where users can verify, adjust, and manage the skills extracted by the AI. The application workflow guides users through job description analysis, match scoring, and document generation, offering intuitive controls for tone, strictness, and skill weighting. Finally, the output layer assembles everything into polished, ATS‑friendly PDFs using HTML/CSS templates and dynamic injection of matched skills. Altogether, the resume-skill-engine functions as a complete end‑to‑end system for transforming raw resume data and job descriptions into tailored, high‑quality application materials.
